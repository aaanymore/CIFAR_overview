# CIFAR-10 Classification and Image Segmentation

The [`cifar.ipynb`](./cifar.ipynb) notebook demonstrates two computer-vision
tasks with TensorFlow:

- image classification on CIFAR-10 using a convolutional neural network;
- semantic segmentation on a small sample from the Oxford-IIIT Pet dataset.

## Run the notebook

Open `cifar.ipynb` in Jupyter or VS Code and execute the cells in order. The
notebook installs TensorFlow and TensorFlow Datasets and downloads the datasets
when run. Training may take several minutes depending on available hardware.
